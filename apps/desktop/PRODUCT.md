# Tool Logger

Platform: MyGo webview on Linux/macOS and ordinary local browsers, React/Graphite UI.

Developers observe Codex/OpenCode tool activity across local processes, SSH hosts and containers. The source sidebar scopes a searchable call table, metrics/charts and right inspector. Retain Graphite light/dark identity, desktop keyboard behavior and responsive browser layouts.

The independent collector owns HTTP/SQLite; UI data uses REST exclusively. Each view owns a loopback gateway with an immutable Unix or pinned TLS connection. The MyGo shell owns window/menu lifecycle and desktop preferences. Plugins journal complete payloads; supervised Node workers deliver authenticated HTTP. Window close, UI Quit, browser close and logout leave collection running. The CLI manages collector startup and shutdown.

Single user, full retention, no automatic deletion. Source UUID defines identity; hostname/container labels aid recognition. Private-network access is explicit. Source write tokens cannot query/administer.

Success: quickly find a call and understand its observed lifecycle/original evidence without inferring success from result presence. Loading, empty, offline, rejection and retry states stay actionable. Keyboard focus, selectable JSON, system theme, resizing, accessible labels and reduced motion matter. Preferences, sessions and native profiles belong to each connection. The local view seeds compatible native preferences while preserving original files. Track parity in docs/native-parity.md.
